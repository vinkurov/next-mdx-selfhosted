Этот материал существует ради одной проверки: в продакшен-сборке его быть не
должно, а в `npm run dev` он должен открываться.

Так автор видит черновик до публикации, не выкладывая его. Проверить можно двумя
командами:

```bash
npm run build | grep draft-example   # пусто
npm run dev                          # страница открывается
```

Если однажды фильтрация сломается, эта страница появится в выводе сборки — и это
заметно сразу, в отличие от молчаливой утечки черновика в прод.
